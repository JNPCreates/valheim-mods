# ExpandedRadii

**Mod version:** 1.0.0  
**Built for:** Valheim 1.0.16 with BepInExPack 5.4.2350. Gameplay and multiplayer features need further testing.

**Mod version:** 1.0.0

Increases the distance used to find comfort pieces and the allowed distance between a crafting station and its upgrade pieces. By default, the comfort search radius is 20 meters instead of 10, and station upgrade range is doubled.

## Install

Install BepInEx for Valheim, then place `ExpandedRadii.dll` in `BepInEx/plugins` and start the game.

## Configure

BepInEx creates `BepInEx/config/com.JNP.ExpandedRadii.cfg` after the first launch. `[Comfort] Enabled` turns the comfort change on or off, and `ComfortRadius` sets its radius in meters. `[Station Upgrades] Enabled` controls the upgrade change, and `UpgradeRangeMultiplier` scales each upgrade's original range.
