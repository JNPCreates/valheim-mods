# NoRainDamage

**Mod version:** 1.0.0  
**Built for:** Valheim 1.0.16 with BepInExPack 5.4.2350. Gameplay and multiplayer features need further testing.

**Mod version:** 1.0.0

Patches the game's `WearNTear.UpdateWear` handling of roof wear. Its effect on rain damage needs gameplay verification before this mod is offered as a working release.

## Install

Install BepInEx for Valheim, then place `NoRainDamage.dll` in `BepInEx/plugins` and start the game.
