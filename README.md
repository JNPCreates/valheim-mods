# Valheim Mods

Valheim mods for BepInEx. Each mod folder contains its DLL and a README with features, installation, and configuration.

Install BepInExPack Valheim 5.4.2350, close the game, then copy the mod's DLL into `Valheim/BepInEx/plugins` or your mod manager profile's plugins folder. If a mod has settings, BepInEx creates its config file in `Valheim/BepInEx/config` after the first launch.

These DLLs were rebuilt against Valheim 1.0.16 on September 28, 2026. Compilation and patch checks passed; gameplay and multiplayer features have not all been retested. `ExtraInventoryRow` is absent because it has no working 1.0.x build.
