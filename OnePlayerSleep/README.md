# OnePlayerSleep

**Mod version:** 1.0.0  
**Built for:** Valheim 1.0.16 with BepInExPack 5.4.2350. Gameplay and multiplayer features need further testing.

Version **1.0.0**. Lets the night advance when any one player is sleeping, instead of waiting for every player. It changes Valheim's shared sleep check, so install it on the host or dedicated server for multiplayer use.

## Install

Install BepInEx for Valheim, copy `OnePlayerSleep.dll` into `BepInEx/plugins`, and restart the game or server. There is no mod configuration.
