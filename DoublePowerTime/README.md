# DoublePowerTime

**Mod version:** 1.0.0  
**Built for:** Valheim 1.0.16 with BepInExPack 5.4.2350. Gameplay and multiplayer features need further testing.

**Mod version:** 1.0.0

Multiplies the duration of guardian power status effects. The default multiplier is `2`, extending a five-minute power to ten minutes.

## Install

Install BepInEx for Valheim, then place `DoublePowerTime.dll` in `BepInEx/plugins` and start the game.

## Configure

BepInEx creates `BepInEx/config/com.JNP.DoublePowerTime.cfg` after the first launch. Set `PowerDurationMultiplier` in `[General]` to change the duration. The default is `2`; `1` keeps the original duration.
