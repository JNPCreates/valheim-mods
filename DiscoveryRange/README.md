# DiscoveryRange

**Mod version:** 1.0.0  
**Built for:** Valheim 1.0.16 with BepInExPack 5.4.2350. Gameplay and multiplayer features need further testing.

**Mod version:** 1.0.0

Increases the radius that reveals terrain on your map as you explore. The default multiplier is 2x the game's base discovery radius.

## Install

Install BepInEx for Valheim, then place `DiscoveryRange.dll` in `BepInEx/plugins` and start the game.

## Configure

BepInEx creates `BepInEx/config/com.JNP.DiscoveryRange.cfg` after the first launch. Change `[General] DiscoveryMultiplier` to adjust the discovery radius; `1` uses the base radius.
