# MistClearingStrength

**Mod version:** 1.0.0  
**Built for:** Valheim 1.0.16 with BepInExPack 5.4.2350. Gameplay and multiplayer features need further testing.

**Mod version:** 1.0.0

Increases the mist-clearing range of objects with a Demister component. The default range multiplier is `2`.

## Install

Install BepInEx for Valheim, then place `MistClearingStrength.dll` in `BepInEx/plugins` and start the game.

## Configure

BepInEx creates `BepInEx/config/com.JNP.MistClearingStrength.cfg` after the first launch. `[General] Enabled` controls the mod; `RangeMultiplier` scales the object's original clearing range. `1` uses the original range.
